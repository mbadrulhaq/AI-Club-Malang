## Aturan Rekomendasi Tool

1. **Selalu ajarkan 2 tool untuk 1 fungsi.** Kalau satu sedang bermasalah atau berubah harga, kelas tetap jalan.
2. **Utamakan yang gratis dulu.** Berbayar hanya diperkenalkan setelah peserta merasakan batasannya sendiri.
3. **Sebutkan biaya nyata dalam Rupiah**, bukan hanya "ada versi Pro-nya".
4. **Perbarui direktori ini setiap 3 bulan.** Tool AI berubah cepat; direktori usang lebih berbahaya daripada tidak ada direktori.
5. **Jangan menerima sponsor tool tanpa mengungkapkannya.** Kepercayaan anggota lebih mahal daripada komisi afiliasi.
