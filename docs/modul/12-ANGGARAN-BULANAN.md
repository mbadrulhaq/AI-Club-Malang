## Aturan Pengelolaan

1. Seluruh langganan atas nama **akun komunitas**, bukan akun pribadi Ketua atau mentor.
2. Pool API key diberi **batas pemakaian per kelas** — pantau mingguan, matikan bila melonjak.
3. Kredensial disimpan di pengelola kata sandi bersama, akses terbatas Ketua + Koord. Kurikulum.
4. Laporan pemakaian dibacakan di rapat bulanan, satu baris per pos.
5. Pos yang tiga bulan berturut-turut tidak terpakai **dialihkan**, tidak dibiarkan menganggur.
